⚠️ IMPORTANT: Environment Variables for Vercel Frontend
============================================================

Go to: https://vercel.com/dashboard
→ Select your frontend project
→ Settings → Environment Variables
→ Add these variables:

-----------------------------------------------------------

NEXT_PUBLIC_API_BASE_URL=https://electro-pi-task-manager-47cg.vercel.app/api

NEXT_PUBLIC_SOCKET_URL=https://electro-pi-task-manager-47cg.vercel.app

-----------------------------------------------------------

⚠️ CRITICAL: After adding these, you MUST:
1. Save the environment variables
2. Redeploy the frontend (Deployments → ... → Redeploy)
